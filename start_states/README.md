# Bundled start states

RetroArch save states that challenges load instead of booting the game (`"start_state": "<file>"`
in a challenge). Gauntlet looks for the file in the user's start-states folder first (captures from
the challenge editor and imported packs go there), then here.

States are tied to the core (and often the core version) that made them, and they contain data
from the game, so only add states for games you are allowed to share.
