Games + some challenges to be templated for

RESEARCH NOTES (added under each game). Full address tables are in docs/ram-research.md.
  [DONE ✅]    RAM addresses verified live in RetroDECK RetroArch (values read and poked, screen checked).
  [PARTIAL ✅] Core addresses verified; the challenge itself needs a later save state, or some parts are RA-notes only.
  [RA ONLY 📝] Addresses from RetroAchievements code notes, not checked live (ROM missing or needs a late save).
  "Needs state" = the challenge starts deep in the game; make a save state there before templating.
  [IN ROTATION 🎮] Added to Gauntlet: gauntlet_data/<slug>.json + a preset; start states go in start_states/.
  Addresses are in Gauntlet's preset address space (see the table at the top of docs/ram-research.md).

Arcade
3rd Strike - win match
  [RA ONLY 📝] RA 11795. Arcade ROMs aren't in RoMM (roms/arcade is empty), so nothing was checked.
  Key RAM: P1 rounds won 0x011380 (u16), P1 HP 0x068D08, P2 HP 0x0691A0, timer 0x011374, VS flag 0x0113B6,
           P1/P2 human flags 0x0156E1 / 0x0156E0.
  Win: P1 rounds won reaches 2 while P2 HP = 0. Find the P2 rounds address with the Memory Lab (probably next to P1's).
  Other challenges: win with a perfect (0x016B4B); win a round with a super art (gauge 0x0695BC);
           arcade run, beat N opponents; win using a random character.

galaga - beat 5 stages
  [RA ONLY 📝] RA 12138. Not in RoMM.
  Key RAM: stage 0x001021, lives 0x001020, in-game flag 0x000C12, hits 0x001044, shots 0x001046,
           score digits 0x0003F8-0x0003FD.
  Win: stage >= start + 5 while 0x000C12 = 1.
  Other challenges: perfect on a challenging stage (0x000210 = end of bonus stage); get a dual fighter (0x001027 = 1);
           hit ratio >= 80% (hits/shots); highest score over 3 stages.

breakout - beat a stage
  [SUBSTITUTE ✅] Atari Breakout (1976) is discrete logic with no CPU or RAM, so it can't be read.
           Use Arkanoid (NES, RoMM 507, RA 1545): bricks left 0x000F (0 = round cleared, verified),
           round 0x0021, lives 0x000D, demo flag 0x0010.
  Win: 0x000F reaches 0 while not in demo.
  Other challenges: clear a round without losing a life; clear 3 rounds; fastest round clear.

  Key RAM: stage 0x0031 (7 = Copy Robot stage), health 0x006A, lives 0x00A6, boss HP 0x06C1, stage clear 0x00BB.

           beat Yellow Devil; finish a stage without dying; collect the Magnet Beam.

  Substitute ✅: Tetris & Dr. Mario (SNES, RoMM 88): lines 0x0328/0x0329, level 0x0342, game select 0x1E0E.
  Other challenges: score 100k; reach level 10; a Tetris (4 lines at once); B-type clear;
           Dr. Mario: clear the viruses (0x03E7 = 0); head-to-head vs mode (0x0309 / 0x0809 wins).

  Softened Up (Bull 0x0398=72); all gated on clock 0x0305 == 1 since the game resets these at the bell.
           (verified), so no long save state is needed.
  Key RAM: opponent 0x0001 (6 = Bald Bull), round 0x0006, Mac HP 0x0391, opponent HP 0x0398,
           wins 0x0170/0x0171, losses 0x0172/0x0173, hearts 0x0323/0x0324.
  Win: Mac wins counter goes up while 0x0001 == 6.
  Other challenges: beat Glass Joe in round 1; KO without getting hit (0x0391 stays full); win with 3 stars banked;
           beat Bald Bull 2 (0x0001 = 9); beat Mike Tyson (0x000D).
